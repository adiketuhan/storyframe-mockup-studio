# StoryFrame Mockup Studio 🎬📱

> **Studio Mockup Storyboard Cerita Bergambar Multi-Slide Realistis (3:4 High-DPI 1080x1440)** untuk TikTok, Instagram Carousel, WhatsApp Drama, dan Media Sosial.

---

## ✨ Fitur Unggulan

### 1. 5 Format Template Media Sosial Pixel-Perfect
- 💬 **WhatsApp**: Balon chat masuk & keluar, bubble tail otomatis, Voice Note dengan visual audio waveform, pesan dihapus (*deleted*), lampiran foto, wallpaper doodle, dan **Fitur Blokir Kontak (Konten Lucu & Drama)**.
- 📸 **Postingan Instagram Feed**: Header profil, story ring, tag lokasi, foto utama feed, action bar interaktif (Love merah menyala), likes counter, caption multiline, dan preview komentar.
- 💌 **Instagram DM**: Chat balon gradien ungu-biru & bubble gelap khas Instagram, status *"Dilihat [Jam]"*, badge centang biru, dan banner akun diblokir.
- 🐦 **X (Twitter)**: Nama akun, @handle, verified badge (Blue & Gold), tweet multiline, foto lampiran, label perangkat (*Twitter for iPhone*), format timestamp, views, reposts, quotes, likes, dan bookmarks counter.
- 🧵 **Threads**: Garis alur utas vertikal (*thread line*), layout minimalis, lampiran media, interaksi, dan balasan bersambung (*nested replies*).

---

### 2. 🎭 Sistem "Setting Peran" (Manajemen Karakter & Pemeran)
- Tetapkan daftar tokoh cerita di awal (**Nama, Handle, Label Peran, Foto Profil, Status Online/Last Seen**).
- **1-Click Quick Cast Picker**: Cukup 1-klik avatar karakter pada editor mana pun untuk langsung mengisi seluruh data profil secara konsisten dan mencegah salah akun.

---

### 3. 📝 Script-to-Story Studio (Regex Text Parser)
- Tulis atau paste seluruh naskah cerita dalam format teks polos sekali jalan.
- Sistem regex secara cerdas menyusun seluruh slide, tokoh pemeran, balon chat, postingan feed, tweet, dan pop-up notifikasi secara otomatis yang siap diedit kembali secara visual.

---

### 4. 📱 Indikator Halaman & Judul di Luar Mockup (Zero-CORS High-DPI Export)
- **Tangkapan Layar 100% Bersih & Otentik**: Screenshot di dalam mockup tidak dirusak oleh watermark buatan.
- **Bar Indikator di Bawah Bingkai HP**: `[Judul Konten] • Halaman 01/05`.
- **Ekspor Otomatis Terurut**: File diunduh dalam format 1080x1440 PNG / Batch ZIP dengan penamaan urut (`slide-01_...png`, `slide-02_...png`) sehingga tidak akan tertukar saat diunggah ke TikTok Carousel.

---

## 🛠️ Menjalankan Proyek Secara Lokal

```bash
# 1. Install dependensi
npm install

# 2. Jalankan server development
npm run dev

# 3. Build untuk produksi
npm run build
```
